# 📖 Second Brain Operating Manual — How to Use This Vault

Welcome to your personal **SQL Server + Data Engineering Second Brain**, systematically engineered from [MaharaTech Course 2305: Implementing and Developing SQL Server Objects](https://maharatech.gov.eg/course/view.php?id=2305). This vault serves as an active study accelerator during your course and a battle-tested production reference for your career as a Database Reliability Engineer (DBRE) or Data Engineer.

---

## 🧭 Daily & Weekly Study Routine

### 1. Daily Learning Cadence
1. Open [`00 - HOME/Home.md`](Home.md) or [`00 - HOME/Course Dashboard.md`](Course%20Dashboard.md).
2. Choose your current lesson from [`01 - COURSE/`](../01%20-%20COURSE/).
3. Review the **Learning Goal** and **Core Idea** before watching the video lecture.
4. Step through the **Mentor Example** in SSMS or Azure Data Studio.
5. Work through the **Hands-On Lab** and **Challenge**.
6. Check off the items in the **Abilities Checklist** as you master them.
7. Record personal observations, execution plan costs, and takeaways in **My Notes**.

### 2. Spaced Repetition & Weekly Review
1. Every Sunday or end-of-week, open [`00 - HOME/Weekly Review.md`](Weekly%20Review.md).
2. Review lessons marked with upcoming `next_review` dates in the Dataview table.
3. Review flashcards in [`06 - REVISION/Flashcards/`](../06%20-%20REVISION/Flashcards/) and syntax rules in [`06 - REVISION/Cheat Sheets/`](../06%20-%20REVISION/Cheat%20Sheets/).
4. Log any tricky issues or bugs encountered in [`06 - REVISION/Mistakes/SQL Server Mistake Journal.md`](../06%20-%20REVISION/Mistakes/SQL%20Server%20Mistake%20Journal.md).

---

## 🎯 The 4-Stage Mastery Workflow

For every video lesson in `01 - COURSE/`:
1. **Stage 1: Watched** — Watch the official video lecture and mark `- [x] Watched`.
2. **Stage 2: Reproduced** — Run and validate the code pattern in SSMS or Docker and mark `- [x] Reproduced in SSMS`.
3. **Stage 3: Modified** — Solve the **Hands-On Lab** and **Challenge**, marking `- [x] Tested edge cases`.
4. **Stage 4: Documented & Explained** — Formulate notes in your own words, solve the **Mentor Challenge**, and mark `- [x] Documented`.
