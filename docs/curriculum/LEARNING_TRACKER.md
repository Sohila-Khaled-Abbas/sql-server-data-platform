## Definition of Mastery

> [!check] Definition of Done for Each Module
> A lesson is only marked completely verified when all four criteria hold true:
> 1. **Understand:** You can define the feature and explain the problem it solves without referencing code.
> 2. **Reproduce:** You can write the syntax from an empty SSMS query window without copying line-by-line.
> 3. **Modify:** You tested boundary conditions, simulated an error, or altered data types/indexes.
> 4. **Explain:** You can describe its performance, locking, and disaster recovery implications to another engineer.
